# 0.2.26

## English

- Group configuration into model and desktop-assistant cards with responsive layout and clear heading/control/help hierarchy.
- Use shared 30%–300% continuous size controls in configuration and the DSH-themed NewMate menu; persist and synchronize the choice. Default 100% uses a 75%-of-original base size.
- Reuse native drawing resources, batch silhouette shading, and coalesce timed UI frames. Replace per-frame preview window resizing with GPU transforms; reuse the warm renderer.
- Fix menu clipping at 200% DPI, inherit ordered DSH/plugin CSS and position beside the pet.
- Preserve read-only previews, hidden-desktop routing, reverse animations, lease cleanup and all existing component tools.

## 简体中文

- 配置按准用模型与桌面助手分级，采用响应式卡片及标题／控件／说明层次。
- 配置页与 DSH 主题右键菜单共用 30%–300% 连续滑杆，保存并同步大小；默认 100%，本体基准为原来的 75%。

- 修复 200% DPI 菜单裁切，继承 DSH／插件 CSS 顺序，菜单显示在桌宠旁。
- 保留只读预览、隐藏桌面路由、反向动画、租约清理与所有现有组件工具。
