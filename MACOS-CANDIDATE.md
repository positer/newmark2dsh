# macOS 0.3.12 candidate

Source candidate for Space + AX, 100ms user-idle input gating, cursor/focus restoration, native pet preview and normal multi-display CU borders. Not a release and not installed locally.

The macos-validation workflow compiles native CU/pet on standard GitHub-hosted macOS runners, runs isolated JavaScript behavior/source contracts and invokes only the read-only native app_list protocol. No TCC database edits, permission bypass, physical input, Screen Sharing server, remote tunnel or package publishing. Public standard runners are free.

Passing this workflow is not Neo hardware, AX delivery, GUI click, cross-Space restoration or 100ms latency acceptance. Those require a permissioned interactive Mac desktop.
